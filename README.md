# The Ants: Underground Kingdom Gift Codes & Auto Redeem

A Telegram bot for **The Ants: Underground Kingdom** that monitors new gift codes, publishes them, and can automatically redeem them for connected player profiles.

Instead of constantly checking for new promo codes and redeeming them manually, players can connect their profile once and let the bot handle new codes automatically.

## 🐜 Features

### Gift Code Monitoring

The bot continuously monitors for new **The Ants: Underground Kingdom gift codes** and publishes them when they are discovered.

### ⚡ Auto Redeem

Players can connect their game profile to the bot using their **Player ID**.

When a new gift code is found, the bot can automatically redeem it for the connected profile — no need to monitor new codes or enter them manually.

### 👥 Gift Codes for Alliance Chats

The bot can also be added to a Telegram chat used by an alliance.

New **The Ants gift codes** can be delivered directly to the alliance chat, so members can see new codes without following a separate channel or checking external websites.

## How It Works

1. The bot detects a new The Ants gift code.
2. The code is published for players.
3. Players using **Auto Redeem** can have the code redeemed automatically for their connected game profile.
4. Alliance chats connected to the bot can receive new gift codes directly in Telegram.

## Why Auto Redeem?

Gift codes in **The Ants: Underground Kingdom** can appear at different times and may only be available for a limited period.

Auto Redeem removes the need to:

- constantly monitor Telegram channels or websites;
- check whether a new gift code has appeared;
- manually copy and redeem every new code.

The goal is simple: **when a new gift code appears, the bot takes care of the redemption automatically.**
